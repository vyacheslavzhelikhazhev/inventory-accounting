# Изменения

## 1.5.1

- Публичная поставка программы с пустым учетом. Рабочие данные и подключения загружаются отдельно.
- Реквизиты представителя работодателя перенесены в настройки; шаблоны очищены от персональных метаданных.
- Добавлены проверяемая Windows-сборка, полная поставка и отдельное обновление в GitHub Releases.
- Сохранены возможности актуальной версии 1.5: компактные карточки с меню действий, светлая/темная тема, стоимость, акты Word, передачи, перемещения, ремонт, исправление данных без новых актов и общий учет через Битрикс24 Диск с проверкой конфликтов.
