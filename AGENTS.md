# Работа над Матучетом

Этот репозиторий — исходная база программы. Сохраняйте текущий интерфейс, поддержку стоимости, шаблонов Word, передач, перемещений, ремонта и общего учета через Битрикс24 Диск.

- Пользовательские данные хранятся отдельно. Не коммитьте рабочие базы, списки сотрудников/техники, акты, реквизиты, адреса внутренних порталов, ключи, вебхуки и журналы. `seed.json` должен оставаться пустым, кроме универсальных справочников. Тестовые данные только вымышленные.
- Шаблоны должны оставаться обезличенными, включая свойства Word. Реквизиты вводятся в настройках приложения.
- Не запускайте проверки на рабочей папке пользователя и не подключайтесь к его Битриксу для тестирования. Используйте отдельные временные папки и имитации сервера.
- Для изменения проверяйте соответствующее поведение и полный набор `test_shared.run`, который включает проверки учета, стоимости, восстановления, синхронизации и режима редактирования. Сборка выполняется `python scripts/build_windows.py`.
- Перед выпуском обновите VERSION, версии в store.py/ui и CHANGELOG.md. Сначала проверки и сборка, затем коммит и тег. Пользователь просил хранить последующие изменения и готовые сборки здесь; выпускайте только проверенные изменения в рамках его запроса. Не перезаписывайте стабильные теги, не делайте force push.
- Публикуются только исходники и чистые сборки из `release/`. Рабочие ZIP из других папок могут содержать персональные данные и не подходят для публикации.
