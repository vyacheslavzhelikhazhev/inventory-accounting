# Матучет

Учет оборудования для Windows: сотрудники, выдача и возврат, передача, перемещение, ремонт, акты Word, стоимость, история и резервные копии. Есть светлая и темная темы и режим исправления данных без оформления новых актов.

## Скачать программу

Готовые сборки: **[последний релиз](https://github.com/vyacheslavzhelikhazhev/inventory-accounting/releases/latest)**.

- `Matuchet-<версия>-Windows.zip` — полная программа. Распакуйте архив целиком в доступную для записи папку и запустите `Матучет.exe`.
- `Matuchet-<версия>-Update.zip` — обновление существующей установки. Закройте программу, сделайте резервную копию, замените файлы программы из архива. Папку `Данные` сохраняйте отдельно.
- `SHA256SUMS.txt` — контрольные суммы архивов.

Нужны Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. При отсутствии WebView2 установите его с [официального сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
Архивы `Source code`, которые GitHub добавляет автоматически, содержат исходники, а не готовый EXE. EXE пока не подписан цифровой подписью.

## Данные отдельно

В репозитории и сборках **нет сотрудников, оборудования, актов, реквизитов организации и настроек подключения**. При первом запуске создается пустой учет и базовые справочники типов и расположений.

Существующий учет можно подключить двумя способами:

1. В прежней программе создать полную резервную копию. В новой открыть **Настройки → Восстановить из архива**, проверить состав и подтвердить восстановление. Это заменяет текущий учет, поэтому сначала сохраните его копию.
2. При закрытой программе перенести всю свою папку `Данные` рядом с новым EXE. Не копируйте только SQLite без связанных актов. Сначала сохраните исходную папку отдельно.

Рабочие данные не загружайте в GitHub. Excel-импорт в этой версии служит для исправления существующих записей по выгрузке самой программы; первичная загрузка произвольной таблицы не реализована. Для нового учета сотрудников и технику можно добавлять через интерфейс, включая режим редактирования.

В настройках заполните выдающего, его должность, ФИО и должность представителя работодателя, основание полномочий. Пустые реквизиты в актах остаются строками для заполнения.

## Совместная работа через Битрикс24 Диск

Подключение задается локально в настройках. В режиме общего учета изменения передаются через снимки на Диске, а приложение проверяет появление более новой версии и конфликты. Работайте строго по очереди; дождитесь успешной отправки перед передачей работы коллеге. При недоступности Диска изменение общего учета блокируется. Это не серверная многопользовательская база.

Не синхронизируйте открытую SQLite напрямую через папку облачного диска. Подключение на другом компьютере настройте отдельно: защищенный секрет привязан к учетной записи Windows. Перед включением общего учета всем сотрудникам следует установить одинаковую версию программы и сделать резервные копии.

## Режим редактирования

Включается в настройках на текущий сеанс. Позволяет исправлять карточки, сотрудников и справочники без нового акта. Причина и изменения сохраняются в истории, прежние акты не переписываются. Режим не защищен паролем и не является разграничением прав пользователей Windows.

## Разработка и выпуск

Python 3.12 x64, Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts/build_windows.py
```

Скрипт запускает проверки исходников, собирает EXE, проверяет сам собранный EXE и создает два ZIP в `release`. Все проверки используют только искусственные данные. Для запуска исходников: `python main.py`.

GitHub Actions проверяет и собирает изменения ветки `main` и pull request. Готовые промежуточные архивы находятся в Artifacts соответствующего запуска. Для постоянного релиза обновите `VERSION`, версии в коде и `CHANGELOG.md`, затем отправьте тег `v<версия>`: после успешных проверок workflow опубликует сборки в Releases. Стабильные теги и опубликованные архивы не перезаписываются. Без нового коммита и тега новые сборки автоматически не появляются.
